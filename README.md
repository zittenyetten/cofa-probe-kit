# Cofa Probe Kit — 참고자료 안내

**이 README는 시험 문제·과제 지시서가 아니다.** 과제 공간의 README와 이름이 같아도 역할이 다르다. 시작할 때 AI가 **실제 과제 지시서 경로 / 이 참고자료 폴더 경로**를 먼저 구분하도록 한다.

**본시험에서는 필요한 로컬 MD만 참고한다.** 자료집을 따라 새 도구를 설치하거나 MCP·미리보기·호환성을 시험하지 않는다. 이미 제공된 환경에서 실제 과제의 질문·분석·결과 생성·검증을 진행한다. 아래의 선택 자료와 설치 예시는 사용 가능한 기능이 이미 확인됐거나 시험 전 개인 학습이 필요할 때만 찾아본다.

**가져온 자료를 전부 사용할 필요는 없다.** 기본은 실제 지시서 → 중요한 질문 → 필수 결과 → 검증이다. 시작할 때 스킬·역할 분리·템플릿을 적용하거나 WORKLOG를 자동 생성하지 않는다. 이 자료집이 도움 되지 않는 작업은 제공된 지시서와 AI로 바로 진행한다. 자료집 활용 자체를 목표로 삼지 않는다.

**처음이면 [정말 쉬운 사용 안내](START_HERE.md)부터 읽는다.** clone 다음의 시작·질문·결과 확인·제출을 짧게 정리했다.

**15분 사전 체험을 앞두었다면 [체험 체크리스트](TRIAL_15MIN.md)부터 읽는다.** Helper·현업 담당자 질문과 파일 저장·검증·종료 확인을 시간순으로 묶었다. 체험용 요청문은 RUNBOOK 10번에 있다.

## clone했다면 여기서 시작

**긴 명령을 외울 필요 없다.** 작업 공간의 파일 목록에서 `cofa-probe-kit/START_HERE.md`를 열거나, 아래 문구를 제공 AI에 복사한다. 이름만 보고 다른 README를 선택하지 않는다. AI 사용이 허용된 단계에서 최신 과제 안내를 우선한다.

```text
과제 지시서를 읽고 내가 해야하는 요건들이 무엇이 있고, 서한결팀장에게 확인해야하는 부분들이 무엇이 있는지 불렛포인트로 정리해줘
clone한 cofa-probe-kit/START_HERE.md를 읽고 ‘AI가 이어서 할 일’에 따라 도와줘.
실제 과제 지시서와 참고자료 폴더의 경로를 먼저 구분하고, 서한결팀장은 실제 담당자 이름으로 바꿔줘.
인터뷰·역할 분리·검증은 필요한 부분만 참고하고, 조건이 충분하면 결과 생성·검증까지 이어가줘.
설치·설정 변경·기능 실험 없이 현재 안내가 허용한 제공 도구로 진행해줘.
```

이 문구 하나로 **[START_HERE의 AI 진행 안내](START_HERE.md#ai가-이어서-할-일)**가 이어진다. AI가 필요한 인터뷰·역할 분리·검증 절만 선택하며, 사용자는 다른 프롬프트를 외우거나 이어 붙이지 않아도 된다. 담당자 질문 전달·실제 답변 전달·결과 확인·제출은 사람이 한다.

진행 상태가 궁금할 때만 같은 AI 세션에서 **`진행 점검`**이라고 입력한다. 현재 대화·결과·기존 기록으로 짧게 점검하면 된다. `WORKLOG.md`는 과제에서 요구하거나 사용자가 요청한 경우만 만들며, 기존 파일이 있으면 필요한 변경만 이어 쓴다.

현업 담당자 질문과 결과 검사는 [인터뷰·역할 분리·QA 절차](references/interview-qa-methods.md)의 필요한 부분만 참고한다. OOO·Superpowers의 공개 원칙과 기존 안내를 정리한 MD이며 설치가 필요 없다. 역할 분리는 같은 AI의 순차 검토가 기본이고 스킬은 기존 하나를 유지한다. RUNBOOK의 개별 요청문은 특정 부분만 다시 요청할 때의 선택 자료다.

Clone만으로 안내나 스킬이 자동 실행되지는 않는다. 위 시작 문구를 입력했는데 파일을 찾지 못하면 실제 폴더 위치만 알려준다. 다른 폴더 이름으로 clone했다면 시작 문구의 이름을 실제 이름으로 바꾼다.

**외부 검색 없이 사용한다.** 한 번 받아 둔 MD·빈 양식·PDF·이미지는 로컬에서 읽고, HTML은 제공 환경이 기존 파일의 내부 미리보기를 지원할 때만 연다. 이 자료를 읽기 위한 Node·서버 설치나 실행은 필요 조건으로 두지 않는다. 출처 URL은 참고 표시이며 실시간 조회가 필수인 구조가 아니다. **최초 clone은 저장소에 접근할 수 있어야 한다.** 검색 차단과 GitHub 접근 허용은 별개이며, clone도 막히고 받은 자료도 없다면 이 묶음을 사용할 수 없다. 상세 대응은 [RUNBOOK](RUNBOOK.md#외부-검색이-안-되는-환경)을 따른다. 제공 AI 자체의 모델 연결은 별도이며, 추가 라이브러리·ooo·omo의 실행 조건은 [레포별 재점검](REPOSITORIES.md)에서 구분했다.

## 이 자료의 목적

공개 인터뷰를 참고해 만든 한국어 업무 보조 자료다. **요구 확인 → 작은 실행 → 결과 검증 → 근거 설명**에 필요한 문서만 묶었다. Cofa·KRAFTON·특정 대회의 공식 자료나 성적 보장 도구가 아니다.

제공 모델의 판단 여지를 유지한다. 절차와 검사는 과제 크기에 맞춰 선택하며, 조건이 이미 충분하면 바로 작업한다. 별도 하네스 설정이나 매번 긴 계획·검사 문서 작성을 요구하지 않는다.

**시연과 개인 시험을 구분한다.** 사용자가 설명한 6시간 시연 맥락을 작업 180분＋설명 연습 30분에 그대로 옮기지 않는다. 공개 문서의 시간은 연습 설정이며 개인 응시 공지를 대신하지 않는다. 출처별 확인 범위와 가상 평가의 한계는 [핵심 요약](skills/task-evidence-check/references/cofa-core.md)에 적었다.

## 사용하는 방법

**과제를 시작할 때는 이 문서 위쪽의 시작 문구 하나를 입력한다.** 사용자가 제공한 시연 문장을 첫 줄에 보존했고, 실제 담당자 이름을 사용하도록 안내한다. 인터뷰·역할 분리·검증 선택은 START_HERE가 연결하고, [RUNBOOK.md](RUNBOOK.md)에는 필요한 경우에만 다시 요청할 세부 문구가 있다.

자료를 준비할 때는 1번 요청문으로 clone과 기존 HTML의 내부 미리보기 방법을 요청할 수 있다. 스킬 적용, 용어 확인, PDF·미리보기 실패 시 대안도 그 문서에 모았다. 이후 확정한 실행 문구는 같은 문서를 갱신한다.

직접 실행한다면 다음 명령을 사용한다. 이미 clone한 폴더가 있으면 기존 로컬 파일과 Git 상태를 확인해 원격 갱신 없이 사용한다. 아래 최초 clone은 저장소 접근이 허용되고 가능한 경우에만 수행한다.

```sh
git clone https://github.com/zittenyetten/cofa-probe-kit.git
```

clone 뒤 과제 작업 위치를 유지하고 파일 목록의 `cofa-probe-kit/START_HERE.md`를 읽는다. 그림이 꼭 필요하고 기존 내부 미리보기의 지원·허용이 이미 확인됐다면 [RUNBOOK 1번](RUNBOOK.md#1-자료-준비-clone과-html-열기)을 참고한다. 불명확하면 시험해 보지 않고 로컬 MD로 진행한다. 새 HTML·서버·포트 설정을 만들지 않는다. HTML을 쓸 때는 연결된 이미지·확대 기능이 빠지지 않도록 기존 폴더 구성을 유지한다.

**Clone은 자동 등록을 뜻하지 않는다.** 하위 폴더의 `AGENTS.md`가 상위 과제까지 자동 적용되는 것도 아니다. 기본 시작은 START_HERE만 읽고 실제 과제로 진행하며 스킬 자동 발견 경로에 의존하지 않는다. 제공된 환경을 업데이트하거나 설정을 바꿔 등록을 강행하지 않는다.

스킬 형식은 [OpenAI 공식 문서](https://developers.openai.com/plugins/build/skills)의 `SKILL.md`와 선택적 참고 파일 구조를 따른다. 특정 Probe 버전의 자동 발견·등록·호환성은 검증하지 않았다. 자료집에는 열람 서버·훅·외부 API·패키지 의존성·설치 스크립트가 없다. HTML·CSS·브라우저 JS·이미지는 기존 파일로 보존한다.

반도체 용어만 필요하면 `references/semiconductor-glossary.md`의 해당 항목만 읽으면 된다. 이 참고자료는 새 스킬이 아니며, 전체 문서를 매번 읽거나 별도 설정을 추가할 필요가 없다. 공개 강의 관련 필기를 기술 출처와 대조해 짧게 다시 쓴 요약이며, 강의 영상 전체·이미지의 재배포나 공식 강의 교재가 아니다.

## HTML과 PDF를 열어보기

HTML과 PDF 두 개는 사용자가 제공한 hy-스쿨2 절의 원문 변환본이다. **용어집과 달리 필기의 오탈자·기술적 오류를 수정하지 않았다.** HTML과 이미지 포함 PDF는 해당 절의 강의 화면 69개를 원래 위치에 넣었으며, 텍스트 PDF에서는 제외했다. 정확한 정의는 검수 용어집과 연결된 기술 출처를 우선한다.

HTML은 3–8교시 목차와 같은 화면 안의 이미지 확대·축소·화면 맞춤·**닫기 버튼**을 제공한다. Esc·F11이나 창 전환을 사용 안내에 포함하지 않는다. 이미지와 CSS·JS를 모두 저장소에서 읽으므로 외부 이미지 주소나 CDN은 필요하지 않다. 확대 비율 100%는 현재 화면에 맞춘 크기이며 최대 400%까지 확대할 수 있다. 로컬 브라우저 검사는 실제 Probe의 감독·전체화면 경고 동작을 보장하지 않는다. 검사 범위는 [검증 기록](VALIDATION.md)에 적었다.

**기본은 필요한 MD를 제공 AI로 읽고, 그림은 지원되는 기존 내부 미리보기에서 HTML로 보는 것이다.** PDF 미리보기가 없거나 실패하면 다른 PDF를 반복해서 열지 않는다. PDF는 호환되는 환경을 위한 선택 자료로 보존하며, 원문 이미지 69개는 HTML에도 포함돼 있다. 별도 서버·PDF 도구 설치·다운로드·외부 브라우저 전환은 하지 않는다. 내부 미리보기의 제공 방식과 실제 Probe 호환성은 확인되지 않았으며, 서버 없이 반드시 열릴 것이라고 보장하지 않는다.

## 공개 범위

이 저장소는 공개 출처의 짧은 요약·범용 절차·빈 작업 기록 양식과 사용자가 지정한 hy-스쿨2 절의 HTML·PDF 변환본 및 강의 이미지 69개를 담는다. 개인 메일·응시 링크·토큰·개인 PC 경로·비공개 Notion 주소·다른 절·모의 정답은 포함하지 않는다. 제작 검증의 가상 입력·정답·실행 산출물도 배포 묶음에서 제외했다. 실제 WORKLOG는 이 저장소 밖에 두고 공개 열람 자료에 추가하지 않는다. 빈 양식은 받은 파일 목록에서 읽는다.

실제 사용 가능 여부는 최신 운영 안내에 따른다. 공개 저장소 이용과 그 안의 모든 동작 허용은 별개다. 공개 유지 기간이 지정된 평가에 사용한다면 그 기간을 지켜야 한다. AI 사용 금지 단계에는 사용하지 않는다.

## 출처와 재사용

핵심 요약 안에 조쉬 영상·뉴스레터와 Cofa 공식 페이지를, 반도체 용어집에는 관련 공개 기술 출처를 연결했다. HTML·PDF에는 원문 필기의 공개 영상·기사 출처를 유지했다. 강좌의 전체 구성은 [강남인강의 hy-스쿨2 소개](https://edu.ingang.go.kr/NGLMS/1336/highView?classCd=L2&lectureCd=KIL0015102&pageIndex=1&searchField=S1&type=new)에서 확인할 수 있다.
