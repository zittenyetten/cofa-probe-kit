# Cofa Probe Kit

**처음이면 [정말 쉬운 사용 안내](START_HERE.md)부터 읽는다.** clone 다음의 시작·질문·결과 확인·제출을 짧게 정리했다.

**15분 사전 체험을 앞두었다면 [체험 체크리스트](TRIAL_15MIN.md)부터 읽는다.** Helper·현업 담당자 질문과 파일 저장·검증·종료 확인을 시간순으로 묶었다. 체험용 요청문은 RUNBOOK 10번에 있다.

## clone했다면 여기서 시작

**긴 명령을 외울 필요 없다.** 작업 공간의 파일 목록에서 이 폴더의 `README.md`를 열고, 아래 문구를 제공 AI에 복사한다. AI 사용이 허용된 단계에서 최신 과제 안내를 우선한다.

```text
과제 지시서를 읽고 내가 해야하는 요건들이 무엇이 있고, 서한결팀장에게 확인해야하는 부분들이 무엇이 있는지 불렛포인트로 정리해줘
실제 배포된 과제 지시서가 대상이야. 이 저장소의 안내서를 지시서로 대신하지 마.
과제 지시와 최신 운영 안내를 우선하고, AI 사용이 허용된 단계에서만 도와줘.
외부 웹 검색 없이 제공 자료·로컬 파일·실제 담당자 답변을 근거로 작업해줘.
출처 링크를 열 수 없으면 확인했다고 하지 말고, 결과를 바꾸는 정보 부족만 짚어줘.
서한결팀장은 영상 속 예시 이름이니 실제 과제의 담당자가 다르면 그 이름을 써줘.
지시서 요구·담당자 확인·네 추가 제안·내 결정을 근거 위치와 함께 구분해줘.
clone한 cofa-probe-kit의 AGENTS.md와
skills/task-evidence-check/SKILL.md, RUNBOOK.md의 시작 길잡이와 0번도 참고해줘.
같은 세션에서 빈 WORKLOG 양식을 참고해 실제 과제 작업 공간에 WORKLOG.md 하나로 기록해줘.
공개 참고자료 폴더 밖에 만들고 기존 기록은 이어 써줘. 중요한 시점에만 짧게 갱신하고,
내가 '진행 점검'이라고 하면 상태·누락·막힘·다음 행동을 5줄 안으로 알려줘.
지시서를 찾지 못하면 읽었다고 하지 말고 파일 위치를 물어봐줘.
이후에는 현재 상태에 맞는 다음 행동을 짧게 안내해줘.
담당자에게 물을 질문은 내가 전달할 수 있게 써주고 답변을 지어내지 마.
조건이 충분하면 필요한 결과를 만들고 검증해줘. 매번 모든 단계를 반복할 필요는 없어.
```

그다음은 **[RUNBOOK.md의 시작 길잡이](RUNBOOK.md#시작-길잡이-clone-다음에는)**를 따라간다. 중요한 질문 확인 → 실제 답변 반영 → 실행·검증 → 결과 확인 순서다. 반도체 그림이나 용어가 필요할 때만 같은 문서의 열람 방법을 사용한다. HTML 서버부터 켜야 과제를 시작할 수 있는 것은 아니다.

이후 같은 AI 세션에서 **`진행 점검`**이라고만 입력하면 된다. 실제 기록은 과제 공간의 `WORKLOG.md` 한 개에 모으며, 매 대화 전문이나 별도 보고서를 계속 쌓지 않는다. 이는 AI가 작업하며 갱신하는 방식이며 자동 감시 프로그램은 아니다.

현업 담당자 인터뷰는 [RUNBOOK의 실전 업무 인터뷰 루프](RUNBOOK.md#실전-업무-인터뷰-루프)를 따른다. 결과를 바꾸는 질문을 고르고 실제 답을 작업·검증에 연결한다. 모호한 답의 후속 질문, 확인할 수 없는 조건, 질문 종료와 필요한 경우의 인계까지 기존 스킬 하나에 포함돼 있다.

Clone만으로 안내나 스킬이 자동 실행되지는 않는다. 파일을 찾기 어렵다면 제공 AI에 `clone한 cofa-probe-kit/README.md를 읽고 시작을 안내해줘.`라고 요청해도 된다. 다른 폴더 이름으로 clone했다면 실제 이름으로 바꾼다.

**외부 검색 없이 사용한다.** 한 번 받아 둔 MD·빈 양식·PDF·이미지는 로컬에서 읽고, HTML은 기존 Node와 허용된 내부 Browser로 연다. 출처 URL은 참고 표시이며 실시간 조회가 필수인 구조가 아니다. **최초 clone은 저장소에 접근할 수 있어야 한다.** 검색 차단과 GitHub 접근 허용은 별개이며, clone도 막히고 받은 자료도 없다면 이 묶음을 사용할 수 없다. 상세 대응은 [RUNBOOK](RUNBOOK.md#외부-검색이-안-되는-환경)을 따른다. 제공 AI 자체의 모델 연결은 별도이며, 추가 라이브러리·ooo·omo의 실행 조건은 [레포별 재점검](REPOSITORIES.md)에서 구분했다.

## 이 자료의 목적

공개 인터뷰를 참고해 만든 한국어 업무 보조 자료다. **요구 확인 → 작은 실행 → 결과 검증 → 근거 설명**에 필요한 문서만 묶었다. Cofa·KRAFTON·특정 대회의 공식 자료나 성적 보장 도구가 아니다.

제공 모델의 판단 여지를 유지한다. 절차와 검사는 과제 크기에 맞춰 선택하며, 조건이 이미 충분하면 바로 작업한다. 별도 하네스 설정이나 매번 긴 계획·검사 문서 작성을 요구하지 않는다.

**시연과 개인 시험을 구분한다.** 사용자가 설명한 6시간 시연 맥락을 작업 180분＋설명 연습 30분에 그대로 옮기지 않는다. 공개 문서의 시간은 연습 설정이며 개인 응시 공지를 대신하지 않는다. 출처별 확인 범위와 가상 평가의 한계는 [핵심 요약](skills/task-evidence-check/references/cofa-core.md)에 적었다.

## 사용하는 방법

**과제를 시작할 때는 [RUNBOOK.md](RUNBOOK.md)의 0번 예시로 지시서의 요건과 담당자에게 확인할 사항부터 정리한다.** 사용자가 제공한 영상의 시작 문구를 그대로 수록했으며, 실제 시나리오의 담당자 이름이 다르면 이름만 바꾼다. 이후 질문·실행·검증 팁도 같은 절에 있다.

자료를 준비할 때는 1번 요청문으로 clone과 HTML 실행을 함께 요청할 수 있다. 스킬 적용, 용어 확인, PDF 열람, 오류 복구와 종료 요청문도 그 문서에 모았다. 이후 확정한 실행 문구는 같은 문서를 갱신한다.

직접 실행한다면 다음 명령을 사용한다. 이미 clone한 폴더가 있으면 기존 로컬 파일과 Git 상태를 확인해 원격 갱신 없이 사용한다. 아래 최초 clone은 저장소 접근이 허용되고 가능한 경우에만 수행한다.

```sh
git clone https://github.com/zittenyetten/cofa-probe-kit.git
cd cofa-probe-kit
```

이제 파일 목록의 `START_HERE.md` 또는 `README.md`를 읽고 제공 AI에서 시작한다. **그림을 내부 Browser로 볼 때만** 다음 서버 명령을 선택한다.

```sh
node serve.mjs --port 8000
```

기존 Node 18.2 이상을 사용하며 추가 패키지를 설치하지 않는다. 서버는 `0.0.0.0`에 연결을 연다. 작업 공간 **Browser의 PORT에 실제 포트 번호**, **URL(경로)에 `/`**를 사람이 입력한다. 서버 터미널은 유지하고, 사용을 마치면 해당 터미널에서 `Ctrl+C`로 종료한다. 포트 충돌·Node 부재 등은 [실행 방법](RUNBOOK.md#5-서버가-안-열릴-때--사용을-마칠-때)을 따른다.

**Clone은 자동 등록을 뜻하지 않는다.** 하위 폴더의 `AGENTS.md`가 상위 과제까지 자동 적용되는 것도 아니다. RUNBOOK의 3번처럼 두 파일을 명시해 읽게 하는 방식은 스킬 자동 발견 경로에 의존하지 않는다. 제공된 환경을 업데이트하거나 설정을 바꿔 등록을 강행하지 않는다.

스킬 형식은 [OpenAI 공식 문서](https://developers.openai.com/plugins/build/skills)의 `SKILL.md`와 선택적 참고 파일 구조를 따른다. 특정 Probe 버전의 자동 발견·등록·호환성은 검증하지 않았다. 열람용 서버 하나 외에 훅·외부 API·패키지 의존성·설치 스크립트는 없다. 서버는 지정한 공개 문서와 이미지·PDF만 제공하며 상위 과제 폴더를 제공하지 않는다.

반도체 용어만 필요하면 `references/semiconductor-glossary.md`의 해당 항목만 읽으면 된다. 이 참고자료는 새 스킬이 아니며, 전체 문서를 매번 읽거나 별도 설정을 추가할 필요가 없다. 공개 강의 관련 필기를 기술 출처와 대조해 짧게 다시 쓴 요약이며, 강의 영상 전체·이미지의 재배포나 공식 강의 교재가 아니다.

## HTML과 PDF를 열어보기

HTML과 PDF 두 개는 사용자가 제공한 hy-스쿨2 절의 원문 변환본이다. **용어집과 달리 필기의 오탈자·기술적 오류를 수정하지 않았다.** HTML과 이미지 포함 PDF는 해당 절의 강의 화면 69개를 원래 위치에 넣었으며, 텍스트 PDF에서는 제외했다. 정확한 정의는 검수 용어집과 연결된 기술 출처를 우선한다.

HTML은 3–8교시 목차와 이미지 확대·축소·화면 맞춤·Esc 닫기를 제공한다. 이미지와 CSS·JS를 모두 저장소에서 읽으므로 외부 이미지 주소나 CDN은 필요하지 않다. 확대 비율 100%는 현재 화면에 맞춘 크기이며 최대 400%까지 확대할 수 있다. 실제 Probe의 Browser 연결은 미검증이며, 로컬 브라우저 검증 범위는 [검증 기록](VALIDATION.md)에 적었다.

허용된 환경의 제공 AI로 clone한 뒤, 작업 공간에서 `output/pdf/hy-school2-notes-images.pdf`를 선택해 제공되는 PDF 미리보기를 시도한다. 실제 Probe의 PDF 미리보기·AI 이미지 읽기 지원은 확인하지 않았다. 미리보기가 없거나 제한되면 차단을 우회하지 않고 텍스트 PDF 또는 용어집 MD를 사용한다. 개인 PC 업로드나 외부 브라우저 접근 허가를 뜻하지 않는다.

## 공개 범위

이 저장소는 공개 출처의 짧은 요약·범용 절차·빈 작업 기록 양식과 사용자가 지정한 hy-스쿨2 절의 HTML·PDF 변환본 및 강의 이미지 69개를 담는다. 개인 메일·응시 링크·토큰·개인 PC 경로·비공개 Notion 주소·다른 절·모의 정답은 포함하지 않는다. 제작 검증의 가상 입력·정답·실행 산출물도 배포 묶음에서 제외했다. 실제 WORKLOG는 이 저장소 밖에 두고 열람 서버의 제공 경로에 추가하지 않는다. 빈 양식은 파일 목록이나 GitHub에서 읽는다.

실제 사용 가능 여부는 최신 운영 안내에 따른다. 공개 저장소 이용과 그 안의 모든 동작 허용은 별개다. 공개 유지 기간이 지정된 평가에 사용한다면 그 기간을 지켜야 한다. AI 사용 금지 단계에는 사용하지 않는다.

## 출처와 재사용

핵심 요약 안에 조쉬 영상·뉴스레터와 Cofa 공식 페이지를, 반도체 용어집에는 관련 공개 기술 출처를 연결했다. HTML·PDF에는 원문 필기의 공개 영상·기사 출처를 유지했다. 강좌의 전체 구성은 [강남인강의 hy-스쿨2 소개](https://edu.ingang.go.kr/NGLMS/1336/highView?classCd=L2&lectureCd=KIL0015102&pageIndex=1&searchField=S1&type=new)에서 확인할 수 있다.

이 저장소에서 새로 작성한 요약·용어집·지침과 열람용 코드에는 [MIT 라이선스](LICENSE)를 적용한다. **`output/pdf/`의 원문 변환본, `viewer/index.html`의 원문 필기·인용, `viewer/images/`의 강의 이미지·교재·로고는 MIT 적용 대상이 아니다.** 원래의 출처 표시를 유지했으며, 해당 자료·링크한 원문·상표의 권리는 각 권리자에게 있다.
