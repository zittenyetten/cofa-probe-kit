# 작업 요청 빈 양식

현재 요청을 빠짐없이 이해하기 위한 선택 양식이다. 지시서·대화에 이미 있는 내용을 먼저 활용하고 필요한 항목만 쓴다. 사용자가 전부 다시 채울 필요는 없다. 미확인은 임의로 채우지 않으며, 영향받지 않는 작업은 진행한다.

- 목적: [누가 어떤 결과를 어떤 일에 사용할지]
- 요청 범위: [생성 / 수정 / 검토 / 설명 중 현재 요청에 해당하는 범위]
- 입력·근거: [실제 파일·문서 위치와 대상 범위, 받은 답변의 근거]
- 확인된 규칙·제약: [명시된 기준·예외·허용 범위, 보존할 원자료]
- 원하는 결과: [필요한 파일·형식·열·단위·정렬·설명 범위]
- 확인 기준: [요구와 대조할 방법·기대 조건, 확인하지 못한 항목 표시]
- 남은 미확인: [결과를 바꾸는 미답변·충돌과 그 영향. AI 제안은 따로 표시]

요청 범위가 검토·설명이면 파일 생성·수정을 자동으로 포함하지 않는다. 기준이 이미 충분하면 추가 질문이나 별도 승인 절차를 만들지 않는다.

이 원본은 공개 빈 양식으로 유지한다. 실제 내용은 허용된 과제 채팅에서 사용하고, 저장이 필요하면 자료집 밖의 기존 과제 기록에 연결한다. 요청마다 새 기록 파일을 만들거나 실제 과제 자료를 외부로 전송·push하지 않는다. 실행한 작업·결정·검증 근거는 기존 [WORKLOG 양식](WORKLOG.template.md)의 역할이다.
