# 작업 기록

빈 양식이다. 실제 기록은 공개 참고자료 폴더 밖의 해당 과제 작업 공간에 `WORKLOG.md` 한 개로 작성한다. 이 원본 양식에 실제 내용을 채우지 않는다. 기존 기록이 있으면 읽고 이어 쓰며 덮어쓰지 않는다. 실제 기록을 외부로 보내거나 Git에 push하지 않는다.

## 필수 요구사항

상태: **미시작 / 진행 중 / 결과 생성 / 검증 완료 / 보류**. 파일이 생겼다는 이유로 검증 완료라고 하지 않는다. 조건이 바뀌면 영향받는 상태와 검사를 다시 확인한다.

| 요구 | 출처·근거 위치 | 현재 상태 | 결과·확인 근거 또는 보류 이유 |
| --- | --- | --- | --- |
|  |  |  |  |

## 중요한 질문·프롬프트

방향이나 결과를 바꾼 질문·요청의 목적과 응답 요약만 남긴다. 매 대화 전문을 복제하지 않는다.

| 질문·요청의 목적 | 받은 답·결과 요약 | 출처·근거 위치 | 작업에 반영할 점 |
| --- | --- | --- | --- |
|  |  |  |  |

## 사용자 결정과 AI 제안

사용자가 실제로 선택한 내용만 결정으로 적는다. 말하지 않은 이유는 **미확인**, 아직 채택하지 않은 내용은 **AI 제안**으로 남긴다. AI가 자율적으로 처리한 일을 사용자 선택으로 바꾸지 않는다.

| AI 제안 또는 선택지 | 사용자의 실제 채택·제외 결정 | 사용자가 밝힌 이유 | 근거 위치 |
| --- | --- | --- | --- |
|  |  |  |  |

## 검증과 남은 한계

해당하는 경로만 기록한다. 검사 상태는 **미실행 / 통과 / 실패 / 보류**로 구분한다. 실제 검사 수행자가 AI인지 사용자인지도 구분한다.

| 대상·입력·기대 | 검사 방법·수행자 | 실제 관측·근거 위치 | 검사 상태·미검증 항목 | 수정 후 재확인 결과 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

- 남은 한계:

범위 확정·첫 결과 완성·중요 수정·제출 직전에 바뀐 부분만 짧게 갱신한다. 기록은 실제 수행과 이해의 증명이 아니며, 서술형 단계의 AI 사용·기록 열람 허가도 아니다.
