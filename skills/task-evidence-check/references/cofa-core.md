뉴스레터와 영상은 **같은 인터뷰**이므로 독립된 증언 두 건으로 세지 않는다. 아래 인터뷰 내용은 이번에 읽은 기사에 근거한다. 제품팀의 설명과 사례는 평가 성능을 독립적으로 입증한 실험 결과가 아니다.

통합 시 뉴스레터의 업무 질문·과설계·가상 평가 화면 설명과 공식 Probe의 근거 연결 설명을 직접 다시 읽었다. 전달받은 캡처 분석에는 원문 요구, 참가자 입력, AI 출력, 시나리오 답변, 가상 평가가 구분돼 있다. 원본 이미지의 중복·잘림·판독 한계는 그 분석의 보고이며 여기서 새로 검증한 결과가 아니다. 상세 전사·로컬 파일 목록·개인 안내는 이 공개 묶음에 옮기지 않았다.

## 공개 자료의 핵심

1. **업무 맥락:** 현업 담당자와 대화하며 드러나지 않은 요구를 찾는 과정을 강조한다. [인터뷰][J]
2. **범위 통제:** 필요 없는 기능을 추가한 과설계는 업무 목적과 어긋날 수 있다. [인터뷰][J]
3. **위임과 검증:** 개발자는 작업 범위와 확인 방법을 함께 설계한다고 설명한다. 개인 업무 사례이며 응시자의 필수 절차는 아니다. [인터뷰][J]
4. **결과와 과정:** 산출물뿐 아니라 AI 대화·도구 사용·검증 기록도 평가 근거로 설명한다. [공식 소개][P]
5. **결과와 설명의 일치:** 사후 질의에서 판단 근거를 설명하고 실제 구현과 대조한다. [공식 소개][P]
6. **환경별 조건:** 스킬·하네스 반입은 고객별 설정 설명이다. 개인의 clone·설치·업로드 허가를 뜻하지 않는다. [인터뷰][J]

## 작업으로 바꾸는 방법 — 작성자의 준비 제안

아래는 작은 과제를 위한 제안이다.

| 단계 | 할 일 | 남길 최소 근거 |
| --- | --- | --- |
| 요구 확인 | 결과를 바꾸는 공백만 질문한다. | 확인 조건·출처·미확인 |
| 범위 결정 | 필수 출력을 정하고 추가 기능을 선별한다. | 선택·제외 이유 |
| 작업 위임 | 입력·처리·출력과 통과 기준을 연결한다. | 작업 지시 |
| 결과 검증 | 원자료·작은 사례로 대조하고 수정 후 재검사한다. | 검사 방법·실제 결과 |
| 본인 설명 | 결정 이유와 검증 범위를 자기 말로 설명한다. | 근거 위치·남은 한계 |

같은 AI의 재확인은 독립 검증이 아니다. 조건 변경 후 관련 결과를 재검사한다. 질문 수·기록량·토큰 소비를 득점 공식으로 추정하지 않는다.

## 시연 분석을 적용할 때 구분할 것

아래는 전달받은 공개 시연 분석을 참고한 구분이다. 상세 감점 수치를 개인 시험의 배점으로 쓰지 않는다.

| 구분 | 준비에 적용할 점 |
| --- | --- |
| 참가자 입력과 AI 출력 | 짧은 시작 요청 뒤의 긴 질문·최소 기능 목록은 AI 출력으로 전사돼 있다. 모두 참가자가 작성한 프롬프트라고 하지 않는다 |
| 원문 요구와 추가 제안 | 음성 처리 방식을 열어 둔 요구에 AI가 텍스트 변환을 제안한 사례가 있다. 가능한 설계와 필수 요구를 구분한다 |
| 업무 담당자와 코딩 AI | 담당자는 업무 상황·판단 기준을 확인할 상대이고, 코딩 AI는 자료 분석·구현을 도울 상대다. 전체 명세나 개발법을 담당자가 대신 정해 줄 것으로 기대하지 않는다 |
| 과제 시연과 평가 시연 | PUBG 인터뷰 연습 과제와 문의 분류 도우미의 가상 평가를 같은 제출물로 묶지 않는다. 뉴스레터도 평가자 화면이 예시임을 명시한다 [J] |
| 내부 처리와 최종 결과 | 대체 결과를 반환해도 화면에서 정상 결과처럼 보일 수 있다. 실패 후 사용자가 실제로 받는 결과·표시·재시도를 확인하는 연습으로 옮긴다 |
| 근거 연결과 실행 확인 | 코드 위치나 저장 화면은 단서다. 해당 코드 본문·실행 경로까지 읽거나 시험했다는 증거로 바꾸지 않는다. ‘미확인’을 ‘기능 없음’으로 바꾸지 않는다 |

**시간도 분리한다.** 시연의 ‘6시간’은 사용자 제공 맥락이며 이번에 읽은 뉴스레터에서는 확인하지 못했다. 공식 행사 페이지의 11:30 시작·16:10 제출 일정과도 같다고 단정하지 않는다. 이 묶음의 **작업 180분＋설명 연습 30분** 설정은 별도의 짧은 연습용이다. 시연의 구현량을 절반으로 줄이면 된다고 보거나, 설명 시간을 구현 시간에 더하지 않는다. 개인 시험의 실제 시간·AI 허용 단계·전체 마감은 그 시험 안내가 기준이다.

## 적용 경계

항상 해당 과제의 최신 안내와 허용된 도구를 먼저 확인한다. 공개 제품 설명만으로 응시 시간, 모델, 제출 형식, 배점, 외부 자료 반입을 확정할 수 없다. 이 문서를 사용했다는 사실만으로 성능 향상이나 실제 Probe 호환성이 검증되는 것도 아니다.
